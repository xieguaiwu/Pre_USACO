# P1201 [USACO1.1] 贪婪的送礼者 (Greedy Gift Givers)

> 来源: USACO Training Section 1.1 · 洛谷 https://www.luogu.com.cn/problem/P1201
> USACO 原题文件名: **gift1.in / gift1.out**

## 题目描述

对于一群 $n$ 个要互送礼物的朋友，要确定每个人**收到的钱比送出的多多少**。

每个人都准备了一些钱来送礼物，这些钱将被**平均分**给那些将收到他的礼物的人。

送出的钱永远是整数：假设送礼人一次向 $m$ 人送出 $n$ 元，每人应得到 $\lfloor n/m \rfloor$ 元，**剩余未送出的钱返还给送礼者本人**。

所有人的账从 0 开始：送钱的人账户减少，收钱的人账户增加。

给出一群朋友（没有人的名字长于 14 字符），给出每个人将花在送礼上的钱和将收到他的礼物的人的列表，请确定每个人收到的比送出的钱多的数目（可为负）。

## 输入格式

第一行一个正整数 $n$，表示人数。

接下来 $n$ 行，每行一个字符串表示人名（**这 $n$ 行的顺序就是最终输出顺序**）。

接下来有 $n$ 段内容，对于每一段：

- 第一行是将会送出礼物的人的名字。
- 第二行包含两个非负整数：第一个是送出的钱的数目（$\in [0,2000]$），第二个 $g_i$ 是将收到这个人礼物的人数（$0 \le g_i \le n$）。
- 如果 $g_i \neq 0$，在下面 $g_i$ 行列出礼物的接受者的名字，一个名字一行（同一段内接受者不重复）。

## 输出格式

输出共 $n$ 行，每行输出一个人的名字和该人收到的钱比送出的钱多的数目（用单个空格分隔）。

名字的顺序应与输入第 2 行至第 $n+1$ 行的顺序相同。

## 说明/提示

【数据范围】$1 \le n \le 10$。

题目翻译来自 NOCOW。USACO Training Section 1.1。

dave 302

owen -359

### 样例解释

五个名字：dave, laura, owen, vick, amr。

1. dave 把 200 分给 laura、owen、vick：每人 66，余 2 退回 dave。
2. owen 送 500 给 dave。
3. amr 把 150 分给 vick 和 owen：每人 75。
4. laura 把 0 分给 amr 和 vick：无变化。
5. vick 送 0 元给 0 个人：无变化（**注意 $g_i=0$ 也要读这段，且不能拿钱数除以 0**）。

验算 dave：$-200 + 2 + 500 = 302$ ✓
